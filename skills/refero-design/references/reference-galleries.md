# Reference galleries

Sites to hand the model **before** design work, not after. Paste two or three
into the prompt and say what you like about each — a named source plus a stated
reason beats an adjective ("make it premium") every time.

This list complements [design-systems/](./design-systems/), which holds system
documentation. These are galleries of finished work: what to point at, not what
to implement.

## By what you need from them

| Need | Go to |
|---|---|
| A component to copy, already built | 21st.dev, shadcn/ui |
| A look or mood, not a full page | Dribbble, Pinterest |
| Real product screens, tagged by flow | Mobbin, Page Flows |
| Real web-app UI by component/pattern | Refero |
| Landing pages, filterable | Land-book, Landingfolio, Lapa Ninja |
| One section studied 50 times over | SaaS Landing Page |
| Motion and typography at the high end | Awwwards, Recent (formerly Godly) |
| A constraint the brief already set | Dark Mode Design, Minimal Gallery |
| The part everyone skips | Footer.design |

## The list

- **21st.dev** — copy-paste React and Tailwind components, hover glows included.
  Hand over a component URL directly.
- **shadcn/ui** — the component base much of the above is built on. Point at a
  block and say "like this".
- **Refero** — real web app UI, searchable by component and pattern.
- **Mobbin** — real product screens from live apps, tagged by flow. Best for
  dashboards and onboarding.
- **Page Flows** — recorded user flows from real products. For onboarding and
  checkout, where the sequence matters more than the screen.
- **Land-book** — curated landing pages, filter by industry and style.
- **Landingfolio** — landing pages plus component screenshots, filter by style.
- **Lapa Ninja** — landing page gallery with a free section library.
- **SaaS Landing Page** — landing pages cut up by section, so you can study 50
  pricing sections in a row. The best way to learn one section fast.
- **Awwwards** — the high end. Motion, typography and layouts that push it.
- **Recent** (formerly Godly) — hand-picked AI, Web3 and portfolio sites.
  Strong hero sections.
- **Dark Mode Design** — only dark sites. Useful when the brief says dark mode.
- **Minimal Gallery** — only minimal sites.
- **Footer.design** — footers only. Nobody designs the footer; this fixes that.
- **Dribbble** — shots and mood boards for a look, not a full page.
- **Pinterest** — the fastest mood board around a style phrase like
  "dark minimal SaaS".

## How to use them well

**Say what you like, not just what you linked.** "Vetra, for the way the hero
holds one idea and the nav disappears on scroll" gives the model something to
apply. A bare URL gives it something to imitate.

**Two or three, not ten.** More references average into a blur. Conflicting
references produce a compromise nobody chose.

**Separate inspiration from ownership.** A reference informs typography,
spacing, contrast, composition and motion. It does not license the borrowing of
proprietary branding or distinctive artwork.

**Galleries skew toward the fashionable.** Everything here is curated for
looking current, which is exactly why [anti-ai-slop.md](./anti-ai-slop.md)
matters alongside it: the most-copied look of a given year becomes that year's
tell. Pull structure and craft from these; take the visual identity from the
subject.
