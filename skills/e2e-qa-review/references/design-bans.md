# Design leave-out list (defaults to name, not "avoid a generic look")

From the Opus 5.5 guide ("name the styles you don't want") and scroll-craft's hard rules. The sweep measures
the starred items; the rest need the visual round. Where the user pinned an existing look, report these,
do not enforce them.

- Cream or off-white page background
- Italic accent words in headings *
- Numbered "01 / 02 / 03" section labels or counters *
- Monospace labels as decoration *
- Pill-shaped buttons *
- An eyebrow above every section (at most one per three sections) *
- Em dashes in visible copy *
- Gradient text, neon glow, zero-offset coloured halo shadows
- A thick coloured border down one side of a card ("side-tab")
- Low-poly / claymation 3D as the default world
- A "scroll" cue, arrow or animated mouse icon
- Invented statistics in counters; stock illustrations that show nothing about the product
- `transition: all`; animating width, height, top or left
