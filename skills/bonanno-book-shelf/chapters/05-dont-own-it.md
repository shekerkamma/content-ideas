# 05 — When you don't own the book

The author does not own a copy of *Decisive*. That skill was built without it,
and the method works for any **framework** book. Every well-known business book
has hundreds of summaries published online; enough of them stitched together
gets most of the way to the book itself.

## Step 1 — Collect written summaries
Ask for the long, chapter-by-chapter ones, not two-paragraph blurbs:
```
Find five or six long, written, chapter-by-chapter summaries of
"Decisive" by Chip and Dan Heath. Prefer summaries that name the
frameworks and give the book's own examples. Save each one as a
markdown file in ~/Books/decisive-sources/ with the source URL at
the top. Skip anything under 1,000 words.
```

## Step 2 — Add three summary videos with the watch skill
Written summaries miss the examples people remember out loud.
```
Use the watch skill on these three videos and save each transcript
to ~/Books/decisive-sources/ as its own file, source URL at the top:
<url 1>
<url 2>
<url 3>
```

## Step 3 — Convert the folder like it's the book
```
/book-to-skill ~/Books/decisive-sources/ decisive
```
Same shape out: SKILL.md, chapters, glossary, patterns, cheat sheet.

## Step 4 — Be honest inside the skill
Add a `sources.md` listing every summary used.

## Decision rule — does the workaround apply?
| The book's value is in | Workaround | Example |
|---|---|---|
| **The process.** Named steps, decision rules, a framework you run | Almost as good as the real thing | Decisive, $100M Offers, The Challenger Sale |
| **The wording.** Annotated ads, headline swipes, verbatim examples | **Buy the book.** Summaries don't carry what you need | Breakthrough Advertising |

What you lose: the author's actual wording, and the long case studies.
