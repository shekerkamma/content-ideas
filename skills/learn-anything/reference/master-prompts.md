# Master Learning Prompts

Six prompts for Step 3 of the Specificity Method. Pick the one that matches what
the user wants to do with the knowledge, or recommend one based on their Step 0 answer.

---

## 1. Feynman Technique
**Best for:** concepts you need to understand deeply

```
"Explain [SPECIFIC GAP] using the Feynman Technique. Start with a simple explanation
suitable for a 10-year-old. Then gradually increase complexity. Identify common
misunderstandings and test my understanding with questions. If I struggle, simplify
the explanation further."
```

---

## 2. 80/20 Learning
**Best for:** practical results fast

```
"Teach me [SPECIFIC GAP] using the 80/20 principle. Identify the 20% of concepts
that will give me 80% of the practical results. Focus only on the most impactful
knowledge first. Provide examples, real-world applications and shortcuts for faster
mastery."
```

---

## 3. Personal Tutor
**Best for:** complete beginners on the sub-topic

```
"Act as my personal tutor for [SPECIFIC GAP]. Assume I am a complete beginner.
Create a step-by-step learning plan from basic concepts to advanced topics. Explain
in simple language, provide examples and practical exercises after each lesson.
Do not move forward until I understand the previous concept."
```

---

## 4. Deep Research
**Best for:** strategy, decisions, or contested claims

```
"Act as a world-class researcher. Analyse [SPECIFIC GAP] from multiple perspectives.
Include historical background, current developments, opposing viewpoints, practical
applications and future trends. Present in a well-structured format with key insights
and conclusions."
```

---

## 5. Learn by Doing
**Best for:** code, tools, or skills

```
"Teach me [SPECIFIC GAP] through practical projects. Give me progressively challenging
tasks that build upon each other. Explain only what I need to complete the current
project. After each project, review my work and suggest improvements."
```

---

## 6. Mastery and Feedback
**Best for:** identifying unknown unknowns or self-assessment

```
"Evaluate my current understanding of [SPECIFIC GAP]. Ask me challenging questions
and identify weaknesses, misconceptions and knowledge gaps. Create a personalised
improvement plan and provide exercises specifically designed to strengthen my weak areas."
```

---

## Quick Reference

| Situation | Use |
|-----------|-----|
| Concept feels abstract, can't picture it | Feynman Technique |
| Need to use this skill ASAP, time-boxed | 80/20 Learning |
| Completely new territory | Personal Tutor |
| Making a decision / choosing between options | Deep Research |
| Learning a tool, framework, language | Learn by Doing |
| Not sure what you don't know | Mastery and Feedback |
