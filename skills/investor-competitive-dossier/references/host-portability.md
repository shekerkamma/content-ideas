# Host portability

## Source of truth

The complete portable package lives at:

```text
skills/investor-competitive-dossier/
```

Host installations and discovery wrappers are not canonical recovery sources.

## Repo discovery surfaces

- Claude Code: `.claude/skills/investor-competitive-dossier/SKILL.md`
- OpenHands/Antigravity: `.agents/skills/investor-competitive-dossier/SKILL.md`
- Codex reads the canonical repo `skills/` catalog when the host exposes it.

The repo discovery files are thin wrappers that route to the canonical package. Do not add
workflow logic to a wrapper.

## Host installations

- Claude Code: `/home/sheke/.claude/skills/investor-competitive-dossier/`
- Codex: `/home/sheke/.codex/skills/investor-competitive-dossier/`
- Windows Hermes Desktop from WSL:
  `/mnt/c/Users/sheke/AppData/Local/hermes/skills/investor-competitive-dossier/`

Install the complete directory, excluding `__pycache__/`, `*.pyc`, backups, and secrets.
After updating the Claude installation, run `bash scripts/sync-codex-skills.sh` when Codex does
not already resolve directly to the canonical repo copy.

## Verification

Run the skill validator against the canonical and each installed directory. Compare complete
trees with `diff -qr`, excluding only product-specific discovery metadata if a host creates it.
Check text files for NUL bytes and reject generated bytecode. Never claim cross-host parity
from file existence alone.
