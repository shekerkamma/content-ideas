# Glossary

**130 nm / 180 nm** — older, larger processes; Deepgrid's catalogue nodes (Ch 4)
**ADC boundary** — the cut between the SiGe RF die and the CMOS digital die on the radar (Ch 10)
**AEC-Q100** — automotive IC qualification standard (Ch 8)
**AS9100 / ISO 9001** — quality management systems audited before AVL listing (Ch 12)
**ASIL-B/C/D** — ISO 26262 automotive safety integrity levels; D is highest (Ch 8, 9, 10)
**ASP** — average selling price per chip (Ch 8–11)
**AVL** — approved-vendor list; lets a buyer purchase from a company (Ch 1, 12)
**AXI-REALM** — QoS/isolation on the DG SDV platform's AXI matrix (Ch 11)
**Building block** — a reusable, silicon-tested digital function; not a chip (Ch 6)
**Buy(Indian) / Buy(Indian-IDDM)** — DAP-2020 categories; IDDM depends on Indian value content (Ch 1)
**CEMILAC / JSS / MIL-883** — military testing and approval standards; together +9–12 months (Ch 5, 12)
**CFAR** — constant false-alarm rate radar target detection (Ch 10)
**Claim labels** — DONE, DESIGNED, PLANNED, ESTIMATED (Ch 3)
**Crash case** — the forecast re-priced as if things go badly (Ch 13)
**DAP-2020** — Indian defence procurement rules (Ch 1)
**Design-complete gate** — verification coverage, no timing failures, clean layout before the factory window (Ch 5)
**Design-in** — one customer engineering a chip into its product; 5–10 per chip needed (Ch 12)
**DG SDV platform** — Deepgrid's reference architecture: triple-lockstep, RV64GCH host, accelerator domains on 64-bit AXI4 (Ch 11)
**DGridRiscV** — Deepgrid's product version of VexiiRiscv; RV32IM_Zicsr, cacheless, deterministic (Ch 7)
**DICE latch / TMR** — area-costly protections against single-event upsets (Ch 4, 8)
**DPSU** — defence public-sector undertaking, e.g. BEL, HAL (Ch 12)
**Failsafe island** — D100's independent link monitor → safe-state FSM → ESC path (Ch 11)
**FPGA** — reprogrammable chip used to prove RTL; 81.25 MHz is its limit here, not the product speed (Ch 3)
**GDSII** — final layout file sent to the factory (Ch 2)
**IHP SG13G2** — free 130 nm SiGe process with ~350 GHz HBTs (Ch 4, 7, 10)
**KGD** — known-good die; test each die before package assembly (Ch 6, 12)
**LDMOS / thick oxide** — high-voltage transistor types on older nodes (Ch 4)
**Lockstep** — two cores running the same program and compared, catching faults immediately (Ch 7, 9)
**LOI** — letter of intent; build gates open on these (Ch 12)
**LRU** — line-replaceable unit inside a vehicle or aircraft (Ch 9, 12)
**Make-II** — procurement route where a successful trial earns a guaranteed order (Ch 1, 12)
**Mask set** — photographic stencils; full set $0.5–1 M; production set ₹1 Cr+ (Ch 2, 6)
**MPW / shared factory run** — many designs share masks; ~100 chips per design; ₹14.3 L on sky130 (Ch 2, 6)
**No buyer, no build** — build money only for chips with a named buyer (Ch 12)
**NRE** — non-recurring engineering; one-off setup cost (Ch 2)
**PDK** — process design kit for a specific factory; sky130 and IHP's are free (Ch 1, 4)
**PIL** — Positive Indigenisation List; bans named imports after a date (Ch 1, 12)
**PMP** — physical memory protection separating software regions (Ch 7)
**Qualification pathfinder** — the simplest chip (SKU-6) sent first through MIL-883 (Ch 9)
**RTL / circuit code** — hardware description before physical layout (Ch 3)
**SCL Mohali** — Indian government 180 nm military-approved factory (Ch 1, 7)
**Screened** — individually tested to a military standard; 10–100x commercial price (Ch 9, 12)
**SiGe** — silicon-germanium; fast transistors needed for 77 GHz radar (Ch 4, 10)
**SiP** — system in package; six mature dies plus a later 28 nm compute die (Ch 6)
**sky130** — SkyWater's free 130 nm PDK; Deepgrid's proven flow (Ch 2, 7)
**SRIJAN** — portal of imported defence items wanted for indigenisation (Ch 1, 12)
**STA / timing analysis** — proof a chip works at its stated clock; unpublished for 200 MHz (Ch 3, 14)
**Stop rule** — a pre-dated decision for a specific bad outcome (Ch 13)
**Three buyer clocks** — list entry, defence filing, tender win (Ch 12)
**Tile** — ~0.02 mm² slot on a TinyTapeout shared die (Ch 6)
**Track B** — the D100 28 nm programme, funded by a separate revenue-gated ₹50 Cr round (Ch 11)
**UCIe** — chiplet interconnect standard deliberately not used (Ch 6)
**Wafer batch** — 25 wafers of 200 mm (Ch 14)
**Yield** — share of working chips per wafer; assumed 85% (Ch 14)
**Zonal controller** — SKU-9; the vehicle's local gateway/I/O/safety layer, not the central computer (Ch 10)
