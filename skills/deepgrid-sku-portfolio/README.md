# deepgrid-sku-portfolio

Agent skill generated from *Mature-Node Silicon for India's Defence and Industrial Base* (DeepGrid Whitepaper, Plain-Language Edition v3, September 2026) and the *Deepgrid SKU Architecture Compendium v3* by Deepgrid Semi, with [book-to-skill](https://github.com/virgiliojr94/book-to-skill).

It covers Deepgrid's frameworks for mature-node chip strategy:
- the 10x cost model and claim labels
- why 130 nm, and the 198-day tapeout loop
- blocks not chips
- qualification and supplier approval
- the defence and commercial routes, "no buyer, no build" and the three buyer clocks
- competition, the crash case and stop rules
- the round and unit economics
- the nine SKUs, the D100 drone SoC and the DG SDV platform

The content is synthesized summaries and analysis, not the source documents' text.

## Install

```bash
npx skills add https://github.com/shekerkamma/deepgrid-sku-portfolio --skill deepgrid-sku-portfolio
```
