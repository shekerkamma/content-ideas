# Synthetic golden path

This directory demonstrates the minimum complete chain for one slide using the synthetic Asterion/NovaGrid example.

1. Start from `../prompts/sample-prompts.md`.
2. Record claims and gaps in the evidence ledger.
3. Convert the Story Architect page job into the completed content contract.
4. Apply `../review-control-traces/grill-to-meta-loop.json`.
5. Select `competitor-threat-profile` from the archetype catalog.
6. Apply the completed design contract.
7. Render with the current client template, not the neutral HTML skin.
8. Validate the run, OfficeCLI output, native PowerPoint render, accessibility order, and claim-slide traceability.

The example proves artifact wiring only. It contains no reusable market evidence.
