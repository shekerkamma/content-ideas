# Design system

## Visual thesis

Use a white analytical field with restrained brand authority. One dominant exhibit carries the
argument; evidence and decision rails support it. Avoid dashboard chrome.

## Page geometry

- 16:9 canvas; minimum 0.5-inch safe margins.
- Twelve-column grid with consistent gutters.
- Title zone: 12–16%.
- Analytical exhibit: 58–66%.
- Implication/decision/trigger rail: 14–17%.
- Footer/source: 3–5%.
- Preserve at least 20% negative space.

## Hierarchy

```text
assertion title > exhibit verdict / hero metric > primary evidence > annotation > source/footer
```

Set sizes explicitly. Use the reference template when it defines stronger rules. Never solve density
by shrinking substantive content below the agreed minimum.

## Semantic color

- Navy/ink: authority and structure.
- Green: verified conclusion, chosen direction, or positive decision.
- Slate: attributed claim or neutral comparator.
- Amber: qualified interpretation/watch condition.
- Coral/red: insufficient evidence, disqualifier, or stop condition.

Evidence status color must not also encode threat or magnitude.

## Analytical archetypes

| Archetype | Use | Encoding requirement |
|---|---|---|
| Comparison field/matrix | 2–4 comparable entities or control points | Explicit dimensions/axes |
| Heatmap | entities × buying arenas or gates | Defined ordinal scale plus separate confidence |
| Evidence ladder | claim maturity and proof quality | Confidence increases by rung |
| Causal mechanism | signal → consequence → response | Arrows carry verbs; one sentence per stage |
| Qualification funnel | narrowing opportunities or claims | Each gate has an exclusion rule |
| Timeline | events and response windows | Sequence; distance only means duration when evidenced |
| Waterfall/bridge | quantified or directional contributions | Scale must be defensible; label directional views |
| Decision ledger/table | dense evidence and status | Highlight the row that changes the decision |
| Control-point map | ownership/accountability across stack | Layers and owners clearly separated |
| Scenario tree | conditional choices | Branch triggers and endpoints visible |

## Prohibited patterns

- generic four-card dashboards;
- cards nested inside cards;
- paragraph walls in narrow columns;
- repeated title/body language;
- decorative pills and icons;
- unscaled bars presented as data;
- source URLs in the body;
- multiple dark footer bands;
- generated images containing text or evidence;
- repeated layouts without analytical reason.
