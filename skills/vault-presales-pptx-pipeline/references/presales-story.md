# Pre-Sales Story Rules

## Spine

Every deck must answer:
1. Why now?
2. What pain is measurable?
3. What changes in the operating model?
4. What system architecture makes it real?
5. What proof will convince the buyer?
6. What pilot can start now?
7. What decision is needed?

## Proof Objects

Use proof objects instead of claims:
- architecture diagram,
- workflow map,
- data table,
- implementation timeline,
- metric bridge,
- risk register,
- pilot scope box,
- decision checklist.

## Audience

Default audience:
- enterprise architects,
- manufacturing leaders,
- pre-sales teams,
- client IT/product stakeholders.

Avoid generic AI claims. Tie every slide to operational impact, integration path, or decision support.
