# Vault POC Factory Pipeline

Turn research and ideas into enterprise AI POC assets.

## Pipe

1. Start from a source note in `content-research/`, `Ideas/`, `Knowledge/`, or `architecture/`.
2. Identify the buyer/use case: [[TMNA]], [[SAP]], [[Hyundai Plant Operations MOC]], or general [[enterprise AI]].
3. Create or update a `Projects/` note.
4. Create task notes for build steps.
5. Update `Boards/Work.md`.
6. Link back to source research and MOCs.
7. Add daily/dev-log entries when implementation work happens.

## Project Brief Shape

- `## Problem`
- `## Demo Outcome`
- `## Architecture`
- `## Data Needed`
- `## Build Tasks`
- `## Source Research`
- `## Related`

## Grounding Rules

- A POC asset must cite source notes.
- A POC must name the system boundary and user outcome.
- Prefer small demos that prove one workflow.
- Do not create broad project pages without tasks.
