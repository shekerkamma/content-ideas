Find Your Data Source

Every scraper starts with a URL. Open the page, right-click, inspect. The data you need is in the HTML — you just need to know where to look.

import requests
from bs4 import BeautifulSoup

page = requests.get("https://example.com")
soup = BeautifulSoup(page.text, "html.parser")
