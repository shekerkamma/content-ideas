Logo Design

Usage Rules

Clear Space

Maintain 1x the height of the first letter as minimum clear space on all sides.

Minimum Size

24px height minimum for digital. 8mm for print. Below this, legibility degrades.

Do

Use on solid backgrounds only — dark primary or light background. Accent color on the second word is mandatory.

Don't

Don't stretch, rotate, outline, add effects, change the font, or remove the accent color from the second word.
