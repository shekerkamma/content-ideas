Model  ·  Convention over configuration
Each capability is a file at a known path.
agent/  —  source of truth
agent/
├── instructions.md            # always-on prompt
├── tools/
│   ├── run_sql.ts             # => tool "run_sql"
│   ├── list_orders.ts
│   └── post_to_slack.ts
├── skills/
│   ├── refund-policy.md       # on-demand playbook
│   └── sql-style-guide.md
├── subagents/
│   └── reviewer.ts            # own context
└── channels/
    ├── http.ts
    ├── slack.ts
    ├── discord.ts
    └── github.ts
instructions.md
Always‑on system prompt
The agent’s identity, rules and defaults — one Markdown file.
tools/*.ts
One typed TypeScript function per file
Filename becomes the tool name. run_sql.ts ⇒ tool run_sql. Nothing to register.
skills/*.md
Markdown playbooks, loaded on demand
Domain knowledge kept out of the base prompt — pulled in when it’s needed.
subagents/*.ts
Child agents with their own context
Delegate scoped work — a reviewer, a planner — without polluting the parent’s window.
channels/*.ts
Entry points: HTTP · Slack · Discord · GitHub
PATH = CAPABILITY · FILENAME = NAME Slide 04
