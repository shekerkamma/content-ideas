Playbook
Pilot the pattern on one bounded workflow.
Clear owner. Slack surface. Rules encoded as skills. Risky calls gated by approvals and evals.
01
Pick
One bounded internal workflow.
Clear owner. Real users. Slack as the surface. Not a customer-facing agent — yet.
02
Build
Instructions + typed tools + one skill.
instructions.md  +  a few tools/*.ts  +  one skills/*.md. Let the plugin scaffold.
03
Encode
Rules that must stay consistent → Markdown.
Refund policy, SQL style, escalation path. One .md per rule — readable, review-able, diffable.
04
Gate & widen
Approvals + eval suite before widening access.
Risky actions require a human click. An eval suite blocks regressions on deploy. Then open the door.
Ship a pilot in weeks, not a platform in quarters.
