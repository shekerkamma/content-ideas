# Pricing Analysis

Date: 2026-07-14

## Pricing Model By Category

AI implementation orchestration:
- Beacon.li: pricing not public; POC/demo-led enterprise motion.
- Unframe AI: pricing not public; managed enterprise AI delivery.

Digital adoption / product experience:
- Pendo: free tier plus custom pricing for paid tiers.
- Whatfix: talk-to-sales / enterprise plan structure.
- Appcues: plan-based packaging, but page drives buyers to calls rather than exposing simple self-serve numbers in the captured source.
- WalkMe: enterprise custom / request demo.

Customer onboarding / implementation operations:
- Rocketlane: public seat-based pricing at $19, $49, and $69 per team member/month billed annually for the captured plans.
- Arrows: request pricing, based on team size and use case.
- Dock: public pricing page exists, but this run did not deeply parse exact package economics.
- GuideCX: quote-led / not verified.

## Transparent Vs Opaque Pricing

More transparent:
- Rocketlane
- Pendo free tier

More opaque:
- Beacon
- WalkMe
- Whatfix
- Unframe
- Arrows
- GuideCX

## Enterprise Custom Pricing Zones

Beacon likely belongs in enterprise custom pricing because it touches implementation execution, audit, security, product logic, and customer data boundaries. That creates real buying friction but is consistent with the risk profile.

## Usage-Based Pricing Risks

If Beacon prices by implementation volume or agent execution, buyers may worry about unpredictable cost. If it prices by seat only, Beacon may undercapture value from implementation compression. A hybrid pricing model may be necessary.

## Buyer Friction Created By Pricing

Opaque pricing raises early friction against transparent tools like Rocketlane. Beacon's answer should be a POC-based value case, not a generic demo.

## Disruptive Pricing Opportunity

Tie pricing to implementation throughput or revenue-recognition acceleration:
- base platform fee
- per-implementation execution tier
- success/value milestone for compressed go-live time

This would differentiate Beacon from seat-based onboarding/project tools.
