This deck is grounded primarily in the video transcript and the successful `/watch` visual extraction pass. External verification was limited to official Claude Code documentation because the request is to convert the video into a client-ready deck, not to produce a market report.

Official Claude Code documentation confirms the relevant product framing:

- Claude Code is an agentic coding tool that can read a codebase, edit files, run commands, and integrate with development tools.
- It is available across terminal, IDE, desktop, browser, and other surfaces.
- The current docs recommend native installation commands for macOS, Linux, WSL, Windows PowerShell, and CMD.
- The docs describe support for MCP, project instructions, skills, hooks, multiple agents, scheduled work, and CLI automation.

## Course Thesis

The course argues that Claude Code is not just a coding assistant for technical users. It is presented as a practical delivery stack for non-technical or semi-technical operators who want to build websites, automations, internal tools, and AI systems they can sell to businesses.

The core move is from "ask an AI for advice" to "give an agent a local project, persistent rules, reusable skills, and permission to execute, test, and refine."

## Deck-Usable Claims

- Browser chat is framed as advisory; Claude Code is framed as execution inside the local project.
- Project rules and reusable skills reduce repeated explanation and improve consistency.
- The course's recommended beginner path is deliberately progressive: websites, automations, then AI systems.
- The most durable method is planning-heavy: build plan, implementation plan, execution, testing, refinement.
- Pricing should start from measurable client value and maintain obvious ROI.
- Business buyers care more about outcomes than whether the implementation uses AI.
