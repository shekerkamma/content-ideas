# Hyperframe Manifest

The `/watch` skill was used twice:

1. URL pass: captions and metadata were extracted; YouTube blocked the raw video stream behind a bot check.
2. Local efficient pass: yt-dlp downloaded the video with browser cookies, then `/watch` processed the local MP4 and extracted 50 keyframes from 2,268 candidates.
3. Section scene passes: `/watch` processed four focused ranges in token-burner scene-aware mode: Section 1 = 94 frames, Section 2 = 117 frames, Section 3 = 230 frames, Section 4 = 23 frames. An interrupted full-video scene pass also left 461 frames.
