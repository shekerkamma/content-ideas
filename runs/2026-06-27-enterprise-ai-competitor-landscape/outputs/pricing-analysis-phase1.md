# Pricing Analysis - Phase 1

Status: `provisional`

Pricing is not source-complete in this phase. This file defines the pricing map to validate.

## Pricing Models By Category

| Category | Likely Pricing Pattern | Buyer Friction |
|---|---|---|
| Foundation Models | Usage/token + enterprise contracts | unpredictable usage cost, vendor lock-in |
| Infrastructure | GPU-hour, inference usage, reserved capacity | capacity planning, cost volatility |
| Agent Frameworks | OSS + team/enterprise SaaS | unclear production cost and support boundaries |
| Enterprise Platforms | seat + usage + enterprise add-on | bundled pricing hides marginal AI cost |
| AI Development Platforms | seat, usage, compute, enterprise tier | fragmented tooling spend |
| Observability | events/traces/evals volume + enterprise | hard to forecast with agent growth |
| Security | enterprise custom or usage-gated | budget owner ambiguity: security vs AI team |
| Governance | enterprise subscription | value seen as compliance until incident occurs |
| Knowledge Management | seat + enterprise search/content volume | overlap with Microsoft/Google/Atlassian stack |
| Vertical AI | per-seat, per-workflow, per-encounter, or outcome-linked | procurement and ROI proof |
| AI Consulting | project, retainer, transformation program | expensive discovery and unclear asset reuse |
| Managed Services | managed capacity, SLA, project/retainer | service margin and dependency risk |

## Transparent vs Opaque Pricing

High transparency likely appears in:

- developer tools
- open-source infrastructure products
- smaller SaaS platforms

Opaque pricing likely appears in:

- enterprise platforms
- governance/security
- consulting/managed services
- vertical AI with compliance or workflow integration

## Disruptive Pricing Opportunities

1. Fixed-price diagnostic replacing expensive discovery.
2. Per-workflow implementation package with clear acceptance criteria.
3. Usage-risk calculator for AI buyers.
4. Governance starter pack priced below enterprise platform bundles.
