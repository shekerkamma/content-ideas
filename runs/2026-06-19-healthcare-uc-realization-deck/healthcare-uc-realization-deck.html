CHAPTER 04 · GOVERNANCE GATESHIPAA · CMS · FDA · ONC · ICH

Five Compliance Frameworks — Every Use Case Is Governed

HIPAA BAA
All PHI processing requires a signed Business Associate Agreement. Anthropic provides enterprise BAA coverage. Pipeline rule: PHI must be tokenized before any LLM call — store token-to-PHI map in HealthLake/FHIR, never pass raw PHI to a general-purpose endpoint.
All 10 UCs
CMS-9115-F
Mandates electronic prior authorization with API interoperability by January 2027. Creates hard regulatory deadline for UC01 — organizations not deploying PA automation now will scramble to comply rather than lead.
UC 01
CMS Info Block
Requires patient-accessible report summaries in plain language. Claude auto-generates these for discharge summaries (UC04, ≤6th grade) and radiology reports (UC09, ≤8th grade) as part of the same pipeline — no separate authoring step.
UC 04 · UC 08 · UC 09
FDA AI/ML 2024
Supports AI-assisted pharmacovigilance with mandatory human oversight. Adverse event classification (UC07) must include a human-in-the-loop review gate before MedWatch submission. Model outputs must be logged with session ID, model version, and output hash.
UC 07 · UC 10
ONC CDS Rules
Requires explainability for AI-based clinical decision support. Rule: administrative AI (PA letters, coding, denial appeals) can fully automate. Clinical AI (treatment recommendations, diagnoses) requires physician sign-off under current state medical practice laws.
