# Deck Storyboard: The 10-Skill Operator Stack

## Slide 1: The 10-Skill Operator Stack for 30-Day Agentic MVPs

Message: This is not a use-case list. It is a repeatable operating system for taking an agentic MVP from problem validation to post-launch iteration.

## Slide 2: The Old Way Burns Budget Before Proof

Message: Traditional dev shops charge for diagnostic, scope, architecture, market scan, QA, deployment, and advisory before the founder has enough proof.

Use only source-backed ranges:

- Diagnostic: $10K-$15K
- Scope doc: $15K-$25K
- Architecture: $20K-$40K
- Build-vs-buy SOW analysis: about $30K hidden inside the SOW
- Market scan: $15K
- Shipping definition / QA: $20K-$35K

## Slide 3: The New Way Is a Gated Operator System

Message: Ten skills replace the bloated front half of the dev-shop motion with a disciplined sequence.

Flow:

Validate -> Scope -> Architect -> Build/Buy -> ROI -> Teardown -> QA -> Data -> Deploy -> Iterate

## Slide 4: Skill #1 - Problem-Solution Fit Validation

Message: Stop the founder from spending 30 days building the wrong thing.

Core artifact: scored 0-30 verdict.

Operator gate: representative users, real buying signal, and hidden regulatory/distribution constraints.

## Slide 5: Skill #2 - 30-Day Scope Definition

Message: Turn a validated problem into a contract-grade 30-day scope.

Core artifact: 1.5-2 page scope with IN scope, OUT OF scope, milestones, risks.

Operator gate: cut founder feature creep and calibrate to actual weekly velocity.

## Slide 6: Skill #3 - Tech Stack + Architecture Design

Message: Define the boring, proven architecture the builder can execute.

Core artifact: stack, schema, RLS, auth, API surface, integrations, folders, env vars.

Operator gate: override generic stack choices, prevent RLS leakage, and protect migration paths.

## Slide 7: Skill #4 - Build vs Buy Decision Matrix

Message: Decide what to build, what to buy, and where lock-in will hurt later.

Core artifact: feature-by-feature matrix with 3-year economics.

Operator gate: account for SaaS pricing creep, niche workflow misfit, and lock-in cost.

## Slide 8: Skill #5 - MVP ROI Business Case

Message: Gate whether the MVP economics justify the build.

Core artifact from available source: breakeven viability rule.

Operator gate: if breakeven is past month 36 in the base case, the solo MVP is not viable.

Note: current source is partial; do not over-specify beyond this without the complete prompt.

## Slide 9: Skill #6 - Competitor Product Teardown

Message: Name the incumbents, expose their bloat, and identify where a focused MVP wins.

Core artifact: 5-10 competitor profiles with pricing, features, onboarding, strengths, weaknesses, copy/avoid list, target gaps.

Operator gate: find non-obvious competitors, read positioning patterns, and flag unverifiable pricing.

## Slide 10: Skill #7 - Acceptance Criteria + Test Plan

Message: Define what "shipped" means before anyone declares victory.

Core artifact: user stories, testable acceptance criteria, edge cases, manual tests.

Operator gate: catch integration-level failures and launch-night failure modes, not just happy paths.

## Slide 11: Skill #8 - Data Architecture Lite

Message: Treat data and analytics as day-1 architecture, not month-12 cleanup.

Core artifact: sources, storage, source of truth, sync, analytics questions, events, data quality guardrails.

Operator gate: surface hidden data stores, manual overrides, and source-of-truth conflicts.

## Slide 12: Skill #9 - Deployment Sequencing

Message: Production launch is a sequence, not a button.

Core artifact: pre-deploy checklist, staging setup, production sequence, smoke test, rollback plan.

Operator gate: verify env vars, production webhook secrets, real payment test, and auth boundary.

## Slide 13: Skill #10 - Post-Launch Iteration Plan

Message: After launch, control iteration with metrics and discipline.

Core artifact: 3 metrics, feedback categories, four-week plan, pivot signals.

Operator gate: stop founders from adding week-1 features and force action on activation, retention, and payment signals.

## Slide 14: The Operator Gate Is the Product

Message: "Where Claude breaks" is the moat. AI accelerates the work; operator judgment prevents false confidence.

Visual: two-column pattern:

- AI generates artifact.
- Operator gates the failure mode.

## Slide 15: The 52-Opportunity Proof Set

Message: The system has already been applied across 52 implementation-reviewed opportunities.

Use as proof of repeatability, not the main story.

## Slide 16: The Market-Facing Offer

Message: We do not sell vague AI transformation and we do not start by selling a build. We bring the operating system to the table: the gated 10-skill path that tells the founder whether to proceed, what to build, what not to build, how to launch, and how to iterate.

Close: "A portfolio of 52 opportunities proves breadth. The 10-skill stack proves execution discipline."
