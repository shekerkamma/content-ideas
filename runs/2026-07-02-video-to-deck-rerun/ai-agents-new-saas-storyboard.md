## BLUF

The opportunity is not "build an agent." The opportunity is to find a narrow,
repeated, expensive human workflow, observe it deeply, encode the operating
rules, sell the first version as labor replacement, and productize only after
the pattern repeats.

## Narrative Spine

1. **Context:** SaaS value creation came from packaging repeatable work into
   software. Agent businesses can do the same, but the starting point changes.
2. **Tension:** Founders are tempted to start with a generic agent idea. That
   produces shallow demos, weak trust, and no obvious buyer budget.
3. **Resolution:** Start with a workflow that already has a paycheck attached.
   Shadow the human, extract the spec, and wrap the agent with controls.
4. **Proof:** The video's hyperframes support the method: unit economics,
   workflow scoring, shadowing, agentic patterns, wrapper/control room, and
   pilot-to-product path.
5. **Decision:** Build the first agent business as a service-first pilot, then
   productize the repeated pattern.
