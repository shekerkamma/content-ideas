# X Thread Draft

1. The next agent opportunity is not "more AI tools."

It is governed operating layers.

2. A useful agent workflow needs sources, memory, tools, schedules, controls, and approval gates.

Without that, it is just another powerful chat session.

3. Example: content production.

Bad prompt: "Let AI write posts."

Useful workflow: source scan -> topic ranking -> sourced brief -> draft package -> human review -> memory write-back.

4. Hermes is interesting because it already maps to that pattern:

memory, tools, files, cron, skills, profiles, model/provider flexibility, and multiple operating surfaces.

5. The v1 content pipeline should not auto-publish.

It should produce review-ready content packages.

Publishing remains human.

6. The first implementation should be boring:

10-20 sources.
One daily run.
Up to 3 briefs.
At most 1 draft package.
Cost cap.
Run log.
No outbound action.

7. That is how agents move from demo to operations.

Pick one recurring workflow.
Define the boundary.
Let the agent compress the work before the human decision.
