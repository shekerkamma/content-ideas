# Storyboard

BLUF: Treat AI-built apps like production systems from the start. The right stack is the one that turns scale, reliability, performance, and cost trade-offs into explicit operating decisions.

1. AI makes prototypes easy; production still needs system design
2. Use four design questions before choosing the stack
3. Modern app platforms compress heavy infrastructure work
4. Pluto is presented as an enterprise-oriented AI-agent app
5. The core architecture separates experience, control plane, and specialized services
6. The recommended repo model keeps agents and developers aligned
7. Convex is treated as the control plane for product state and workflows
8. Specialized services carry riskier domains outside the main app path
9. Payments architecture should match the pricing model
10. Observability is a production requirement, not a cleanup task
11. The explicit trade-off is spending more to protect product experience
12. A repeatable AI-build playbook falls out of the walkthrough
13. Decision: ship AI apps on deliberate architecture, not vibes
