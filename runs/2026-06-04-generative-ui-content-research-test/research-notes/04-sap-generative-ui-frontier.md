# Summary

SAP positions Generative UI as the next stage of enterprise software experience design: interfaces materialize around user intent, remain grounded in live data, and are executed by agents under user control. This is the strongest category-level enterprise positioning source in the set.

# Key Points

- SAP argues the future is not chatbots bolted onto legacy screens.
- The proposed model is intent-centered, grounded in live data, and executed by agents.
- The article explicitly anchors the argument in the mismatch between consumer AI expectations and enterprise software UX.
- SAP ties the idea to Fiori and Joule rather than describing it as a generic experimental concept.

# Enterprise Signals

- This is a strategic UX thesis from a major ERP vendor, not a startup-only narrative.
- It supports the claim that Generative UI is relevant to large enterprise process software, not just greenfield AI apps.
- It implies change-management and governance requirements because the generated interface still needs enterprise controls.

# Relevance To Use Case

This source justifies the "enterprise wedge" for the use case. It is especially relevant for SAP-centered accounts and system integrator positioning.
