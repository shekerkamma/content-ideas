# Hyundai AI Vault

A markdown-first second brain for Hyundai-related AI strategy, dealer operations, enterprise workflows, and implementation notes.

## Folders

- `/raw` — inbox for captured notes, links, screenshots, PDFs, and scraps
- `/wiki` — durable cleaned notes
- `/projects` — active Hyundai workstreams, one folder per project
- `/archive` — processed source material kept as a permanent record

## Retrieval Order

1. Read `/wiki` first for durable knowledge.
2. Read `/projects` for active context and current work.
3. Read `/archive` to confirm provenance or inspect original captured material.
4. Read `/raw` only when the user wants unprocessed inputs.

## The Loop

1. Capture into `/raw`.
2. Translate into `/wiki` using `translate.md`.
3. Move processed source material into `/archive`.
