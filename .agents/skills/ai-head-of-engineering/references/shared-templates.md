# Shared Prompt Templates

## Scope
- Inputs: feature backlog, core moment of value, constraints
- Output: keep / cut / defer, feasibility score, MVP statement

## Scope spec
- Inputs: MVP statement, kept features, hard constraints
- Output: in scope, out of scope, milestones, Friday decisions, assumptions, done criteria

## Stack
- Inputs: use case, team size, cost ceiling, lock-in tolerance
- Output: choice, alternatives, reasoning, ramp-time flags

## Build vs buy
- Inputs: feature list, team capacity, revenue plan
- Output: build / buy / hybrid, 3-year cost math, lock-in callouts

## Estimate
- Inputs: scoped features, team size, confidence target
- Output: hours, dollars, risks, total range, cut list if over capacity

## AI fit
- Inputs: candidate AI use case, volume, failure cost
- Output: fit score, pattern choice, model recommendation, failure modes

## Internal tool
- Inputs: business motion, painful current SaaS, tracked objects
- Output: data model, UI structure, roles/permissions, automations, integrations, exclusions

## Launch audit
- Inputs: build summary, stack, production config
- Output: edge cases, security gaps, readiness checklist, smoke test

## Roadmap
- Inputs: final scope, capacity, launch date
- Output: week-by-week plan, Friday demos, rollback plan, critical path
